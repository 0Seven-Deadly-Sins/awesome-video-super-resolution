# 收录范围与来源

本轮集中回填按 **2024、2025、2026 会议年份**组织，核验日期为 **2026-10-07**。预印本首次发布年份与会议录用年份不同的，以会议年份归档；未找到正式录用来源的近期工作单独标为 arXiv。

范围是所有输出分辨率的视频超分，包含空间超分、连续时空超分、事件辅助、人脸、视频深度、医学、卫星、全景、低照度与去模糊联合任务。通用视频修复只在有明确 VSR 任务证据时收录。例如 Turtle 包含 VSR 实验；仅做噪声或雨雪恢复的工作不因标题含“视频修复”自动入选。纯文生视频、单图超分和 3D 场景超分不纳入本表。

## 分类原则

每篇一个主方向，交叉特征放入补充标签。同一方法的预印本和会议版本合并，避免重复。生成式方法按多步先验、单步蒸馏和 GAN 分开；部署优化、压缩传输、交互引导、事件辅助和专用场景分别编排。分类是阅读导航，不是质量排名。
